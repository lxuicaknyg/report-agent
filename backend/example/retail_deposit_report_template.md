# 零售客户存款经营分析报告

## 一、报告说明

说明本报告的分析口径与数据来源。本章为纯文字说明，不涉及任何统计指标。

数据取自零售客户资产管理余额表与零售客户行为标签表，两表以统计日期和客户号关联。
